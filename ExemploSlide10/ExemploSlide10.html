1. display: flex

1
2
3
O display: flex é uma propriedade do CSS usada para transformar um elemento contêiner em um flex container (contêiner flexível). Isso permite que os itens filhos desse contêiner sejam organizados de forma mais eficiente e flexível em uma única dimensão: linha (horizontal) ou coluna (vertical).

2.1 display: flex + flex-direction: row

1
2
3
A propriedade flex-direction: row; é usada em um contêiner com display: flex para organizar os itens filhos na horizontal, da esquerda para a direita (sentido padrão da escrita ocidental).

2.2 display: flex + flex-direction: row-reverse

3
